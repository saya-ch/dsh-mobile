# DeepSeek Harness Android App

[English](README.md) · [返回项目首页](../../README.md)

DeepSeek Harness 是这个社区维护的 Android WebView App 的显示名称。它直接打开插件提供的已认证 HTTPS 页面，不打包另一套 DSH 前端；App 与手机浏览器获得相同的 DSH 功能，以及电脑端配置的移动页面定制。

当前正式 App 为 **0.7.5**；构建号为 90。npm 插件与 Android App 独立编号、独立更新；插件升级不代表需要重新安装 APK。此次改进见 [0.7.5 更新](#075-更新)。

此 APK 支持 Android 10 及以上系统。iPhone 和 iPad 使用 [Safari 主屏幕 Web App 与可选网页推送](../../docs/WEB_PUSH.md)，不安装 Android 包；本项目不分发原生 iOS App。

## 安装与配对

1. 按[项目快速开始](../../README.md#快速开始)安装并启用插件。局域网配置可通过命令行或电脑端的 **移动访问** 面板完成。
2. 从 [GitHub Releases](https://github.com/saya-ch/dsh-mobile/releases/tag/android-v0.7.5) 安装已签名 APK。原有 HTTPS 通道可选兼容版 `.apk`；arm64-v8a/x86_64 设备使用实验性 iroh 时选完整版 `-iroh.apk`。两包使用相同包名和正式签名，选一个原位升级即可保留配对；不同签名的 Debug 包不能直接覆盖正式版，不要为绕过签名不匹配而卸载或清除数据。
3. 在电脑 **移动访问 → 局域网访问** 中生成密钥／配对链接，或配置远程通道并生成远程配对二维码。在 App 选择对应方式，扫码或粘贴链接。
4. 为电脑命名。每条局域网或远程配对单独保存；手机无需安装 cpolar、Cloudflare 或 Tailscale App。

局域网还提供扫描和手动 `https://IP:端口` 输入。自动发现不能绕过防火墙、校园网隔离或缺失的网络路由；需要使用可达地址或远程通道。手机浏览器另见[项目连接说明](../../README.md)。

## 0.7.5 更新

后台任务提醒直接显示插件提供的内容：当事件带有插件 0.8.8 引入的有界标题和正文时，锁屏记录使用会话显示名与该轮第一行文字；两者都没有时回退到本地化的固定文案，旧插件的行为与之前完全一致。每个字段都会裁成单行、移除控制字符并限长，且不会写入日志。

由 App 单独决定该记录是否投递，并不再报告无法完成的投递：服务按会话与轮次只发一条——相同的 tag 与固定通知 id 会替换而不是追加——在通知被关闭或任务渠道被屏蔽时记录有界的 `notify:blocked` 阶段，而不是声称已投递。`notification.background.get` 现在还会报告 `canPost`（系统权限与渠道的答案，不只是流健康），页面需要在让出投递前读取它。

插件让位时由页面自己发通知：使用插件 0.8.8 时，只有 `enabled`、`connected` 与 `canPost` 同时为真页面才保持静默；权限被撤销、渠道被屏蔽、服务重连中或插件较旧时，页面仍发自己的提醒，不会让该轮完全无提醒。

把来源网段不受信任与配对码过期区分开：当网关返回 HTTP 403 `{"error":"source_network_untrusted"}`（需插件 0.8.9 或更高）时，配对弹窗会说明手机所在网络不在电脑的信任范围内，并指向「额外允许的来源网段」，而不是笼统地说一次性二维码已失效。仍只返回 `forbidden` 的旧插件保持原提示，混合版本行为不变。

在设备列表设置中加入原生「检查更新」：它直接从 GitHub 读取已发布的 App 描述符（不经过已配对网关），比较构建号，提示已是最新，或经用户确认后打开对应的 Android 发布页。不会自动下载或安装，失败只显示可重试的提示。

两种 APK 变体都保留既有签名与现有配对；通知文案需要插件 0.8.8 或更高，配对提示需要插件 0.8.9 或更高。

## 0.7.4 更新

把按修订号寻址的移动端页面载荷缓存在设备上，独立于 WebView 自身的 HTTP 缓存：经重新校验的启动批次可用 `If-None-Match` 校验，并在 304 后直接返回已存正文；按修订号命名的插件组合包按有序模块列表与修订号寻址。只有大小与 SHA-256 都与取回字节一致后才写入缓存；缓存未命中或任何完整性、epoch、归属校验失败都会回退到普通请求；文档、API 响应、凭据与未按修订号命名的资源不参与缓存；清除站点数据或移除已配对设备会清空该存储。后台提醒的常驻通知现在显示真实阶段（连接中、已连接、未连接），并通过 `notification.background.get` 与 `DshMobileBg` logcat 行发布 `connected`、`lastEventAt` 和有界的 `lastError` 阶段；后台服务的完成通知使用独立的 `dsh-task-bg-` 标签，服务会重新绑定到新激活的已配对电脑而不是继续重试原 Origin，活动记录无法提供服务（包括 iroh 配对）时撤回该选项。点击任务通知现在先由页面内的就地钩子在活动页面中打开对应会话，页面未就绪或无法处理该路由时回退到路由跳转。两种 APK 均沿用正式签名，可原位升级并保留已有配对；页面侧的一半需要插件 0.8.7 或更高版本。

## 0.6.5 更新

Android 0.6.5／构建 81 在启动连接、已配对电脑连接、局域网扫描和配对过程中均提供立即可用的 **取消连接**。取消后回到设备列表或可编辑表单，不删除原有配对；**停止重连**保留仍可用的 DSH 页面，空白或失效文档则返回列表。

## 同电脑自动连接

App 0.6.7 配合插件 0.6.16 及以上版本，在设备列表 → 设置 → 同电脑自动连接中提供三种方式：**手动**、**自动检测并提示**、**自动切换并提醒**。默认仍为手动。局域网与远程须分别配对；只有成功原生配对／续期／探测响应中认证的 `installationId` 一致才分组。旧插件或无该字段的旧记录保持独立，直至认证刷新或续期学习，无需重新配对／重置；发现信息、名称和相同地址都不能授权分组。每个入口保留自己的令牌、`instanceId` 固定身份和 CA。

开启检测后，冷启动优先同电脑的有效局域网配对。使用局域网时 Wi-Fi 断开，会提前独立探测可信远程入口，不再等局域网续期超时才处理。前台网络回调及每 30 秒检查仍有防抖、限频与切换冷却。局域网续期仅在临时网络故障时可回退到该电脑可信远程配对；撤销、过期、TLS 和身份错误不会触发回退。后台或过期回调不能切换页面，不重放发送或其他写请求。

**不改 DSH 核心的受限纯文本迁移。** 已打开网页时，“自动检测并提示”会在替换页面前弹窗确认；“自动切换并提醒”可通过插件的公开会话输入接口，迁移当前唯一被观察会话的纯文本草稿（可为空，最大 256 KiB UTF-8）。源 WebView 会保留到目标独立认证成功、通过公开导航接口打开同一会话、恢复文本并读回验证完成。目标原稿必须为空或与待迁移文本完全一致；接管前还需核对目标导入版本和最终源版本。文本变化、目标冲突、迟到回调、导航或认证失败不能授权接管。成功后仅轻提示，接管完成才丢弃源页。同源恢复仍沿用原有页面保留逻辑。

这**不是完整跨地址状态迁移**：附件、结构化引用、命令模式、队列、已观察到的发送／媒体／输入法活动、多个输入会话或协议未知／缺失，不符合该自动迁移路径。源页不符合条件时仍提示确认；目标加载或迁移失败保留源页，不静默丢弃。取消／推迟保留页面。未观察到的隐藏草稿、分离的待完成发送／上传，以及滚动和面板不会迁移；公开接口不能证明这些内部状态全部安全。确认重载前请保存／复制相关内容。

迁移快照和租约仅在内存中短暂保存，不额外持久化跨地址传输数据；目标写入仍会使用 DSH 自身正常的草稿持久化。取消时仅在导入版本仍未变化的情况下回滚本次写入；渲染器崩溃或回滚接口不可用时，不能保证清除已被 DSH 保存的目标草稿。不重放发送或上传。真机覆盖范围与剩余网络限制见[验收与已知限制](#验收与已知限制)。

## 连接恢复与信任

设备记录、可撤销的长期令牌和固定 CA 使用 Android Keystore 加密保存，旧版局域网／远程槽可迁移，无需重新配对。暂时无法解密时会报告错误，不当成空列表或用新凭据覆盖。CA 已过期的记录仍能删除或重新配对，但 TLS 继续拒绝过期证书。

App 只向已保存的精确 Origin 续期短期 Web 会话。局域网地址变化后，可在默认端口发现同一安装实例，并在原有固定证书校验下续期。远程 Origin 失效后无法从旧地址发现新地址，应扫描电脑端当前远程二维码验证；旧设备令牌不会发送给该未验证地址。

发现过程只携带元数据：同时使用 DNS-SD/mDNS、UDP 公告、端口 `3443` 主动查询，以及可见私有 Wi-Fi／热点 `/24` 网段的有限 HTTPS 探测。其他端口或可路由子网可手动输入地址；发现成功不代表已获配对授权。

局域网和自签 FRP 配对会在不发送设备凭据的情况下读取 CA，校验有效期及与配对密钥一致的指纹，然后按精确 Origin 在 App 内固定。其他 TLS 错误一律拒绝，不向系统安装 CA。同一 CA 下续签叶证书无需重配；CA 更换或过期则必须重新核对并配对。

常规远程入口使用系统信任的 HTTPS 证书。[托管自建 FRP](../../docs/SELF_HOSTED_FRP.md) 的公开 CA 路径支持 App 0.3.3+；[既有 frps 的自签入口](../../docs/ATTACH_EXISTING_FRPS.md)需要 App 0.4.6+，普通浏览器不会自动信任其私有 CA。证书有效期不等于无需维护即可持续可用。

临时断网不等于设备被撤销。收到在线撤销通知后，条目显示 **电脑端已移除**，后续探测不会恢复它；离线时被撤销的设备也可能只收到通用的 **配对已过期**，请使用新码重新配对。App 不会向未知令牌暴露设备是否曾被移除。

自动恢复在续期后尽量保留仍运行的 DSH 文档。渲染进程失效或启动失败时可能需要重新打开，未保存状态不保证恢复。受支持的旋转、窗口和键盘变化保留 WebView；系统主题／字体／语言变化、进程终止及渲染失败可能导致重建。

## 文件、相机与输入

### 标准附件

App 0.6.4+ 在 Android 13+ 对支持的图片过滤优先使用系统 Photo Picker，保留网页的 MIME 和多选要求，并遵守系统数量限制。其他过滤、拍摄请求、较旧 Android 或选择器不可用时使用 Documents；无需存储权限，也不保证出现某个厂商的相册。

标准文件回调绑定当前 WebView、Origin 和文档。支持导航监听时，文档替换前撤销旧请求，导航结束后才能再次选择。较旧 WebView 使用可用回调；如换页后选择器不再打开，可更新 WebView，或回设备列表重新打开电脑，无需清除数据。

DSH 的文件入口仍在 **添加** 组；当前附件 owner 支持图片时，Mobile 加入 **拍照** 和 **相册**。仅专用移动页面将 **相册 → 拍照 → 文件** 放在最前；其他官方项目保持上游默认顺序，普通／桌面页面的菜单排序不变。**相册** 打开仅选择图片的标准文件选择器，不请求拍摄；在 App 内使用上文所述的系统选择器，在手机浏览器内使用浏览器的文件选择器，无需新增 Bridge 能力或安装新版 App。**拍照** 仍明确申请相机权限后返回完整分辨率 JPEG。两者均交给 DSH 现有的草稿附件入口处理；取消选择不会添加附件，属于旧会话或已销毁页面的结果会被忽略。排查时可选一张小 JPEG／PNG，检查未发送草稿的预览；尚未提交的文件不必已经成为电脑端图片对象，无需发送模型请求来验证选择结果。

### 键盘与页面空间

系统返回键先关闭支持的网页层级，再处理同源 WebView 历史，根页面退出；模型子菜单先退回上一级再关闭。WebView 上方不显示额外原生工具栏。

原生软键盘适配只在屏幕键盘占据窗口、未报告实体键盘且活动会话输入框聚焦时，把普通 Enter 用作换行。插件另有触屏浏览器规则，也将 Enter 用于草稿换行，触屏设备的外置键盘同样可能使用该规则。菜单、输入法组合和组合键仍交给 DSH，非触屏桌面行为不变；多行消息请点发送，DSH 常规键盘策略下也可用 Shift+Enter 换行。

系统栏、屏幕缺口和键盘空间只预留一次。支持 `HTTP_CACHE_MANAGER`／`MULTI_PROFILE` 的 WebView 为 App 的可复用版本化 DSH 资源提供至少 64 MiB HTTP 缓存配额；旧内核保持默认配额。Chromium 低于 100 的提醒不阻断使用，也不承诺旧内核支持全部 DSH 接口。

App 连接成功不代表网页脚本能够运行。DSH 0.2.1-rc.2 的前端含有 Chromium 92 无法解析的语法；系统内核无法更新时可使用已验证可用的浏览器，不必清除配对。插件的启动反馈与支持范围见[旧内核说明](../../README.md#app-与手机浏览器)。

### 语音

DSH 通过 `getUserMedia` 录音并交给电脑已配置的语音提供方，不使用浏览器 SpeechRecognition 或扩展 Bridge。Android 申请麦克风权限，仅接受配对 HTTPS Origin 的纯音频请求；电脑组件、模型和网络仍需可用，录音授权不代表转写成功。同源前端插件共享该页面权限。

## 通知与扩展

任务提醒依赖 Host 完成事件和待确认卡片。页面仍存活时由网页走原生 Bridge 发通知；在**设置 → 通用设置 → 任务通知**下可显式开启**后台提醒**，由可关闭的前台服务保持与当前已配对电脑的连接，页面被系统挂起后仍可收到完成事件。该服务会显示常驻通知，受 Android 前台服务时限、电池策略和网络影响；iroh 配对暂不支持，断连期间不补发。点击通知可携带有界的同源 `dsh-session` 路由，冷启动或热启动后打开对应会话；其他目标一律回退到 App 根入口。Cloudflare 快速隧道不支持事件流，详见[通道限制](../../docs/CLOUDFLARE_TUNNEL.md#快速隧道的功能限制)。

Android 自身的电池管理仍可能中断投递，而且常驻通知**不代表**事件流是活的：服务一在跑它就在，与连接状态无关。设置 → 通用设置会显示服务的真实阶段（已连接、未连接或最后一次记录到的有界失败阶段），并写入 `DshMobileBg` logcat 行，便于用 `adb logcat` 定位。在会冻结后台进程的厂商系统上（例如小米 HyperOS 的应用电池省电策略），App 侧无法维持这条流：请为该 App 关闭电池限制，或接受提醒在下一次回到前台时才出现。iOS 走网页推送通道，不受此限。

认证页面可通过 `dshMobile` Bridge 调用 `files.pick`、`camera.capture`、分享、剪贴板读写、任务通知／设置、后台提醒（`notification.background.get`／`set`）、切换电脑及页面缩放。扩展单独调用的 `files.pick` 返回一个文件，遵循声明的 MIME 类型，通过 Bridge 返回的文件最多 8 MiB；这不是 DSH 标准附件选择器的大小限制。

Bridge 文件／相机操作串行执行，最长等待五分钟。取消、文档／会话变化或 WebView 销毁会拒绝旧结果并清理资源。浏览器媒体选择等待实际结果、明确取消、中止或超时，恢复焦点不直接视为取消；不支持的能力返回 `unsupported`。

电脑端 `host.mjs` 扩展是另一层受信任 Node.js 代码，原生 Bridge 不能编辑或上传其源码。电脑管理的前端资源及扩展激活见[项目指南](../../README.md)，可选 Worker 执行见 [Worker 指南](../../docs/EXTENSION_WORKERS.md)。

## 安全边界

| 控制项 | Android 行为 |
| --- | --- |
| 传输 | 仅 HTTPS，Manifest 禁止明文流量。 |
| 信任 | 按精确 Origin 使用系统信任或私有配对 CA，不广泛信任用户另装的系统 CA。 |
| 导航 | 同源主页面保留，明确点击的外部 HTTPS 链接交给系统浏览器。 |
| 权限 | 明确扫码／拍照时申请相机权限，DSH 录音时申请麦克风权限，通过前台操作申请或设置通知；后台提醒使用用户显式开启的 `dataSync` 前台服务；标准选文件无需存储权限。 |
| Bridge | WebMessage listener 校验精确顶层 Origin 和主框架，不使用 `addJavascriptInterface`，不暴露任意 Android API。 |
| 限额 | 入站消息 1 MiB、剪贴板 256 KiB、二进制 Bridge 结果 8 MiB、回复 12 MiB。 |
| 凭据 | Bridge 回复不自动附带已保存的配对凭据，也不提供直接读取凭据存储或私钥的接口；剪贴板和所选文件仍可能包含敏感内容，请仅使用可信扩展。 |
| 下载 | 仅当前精确 Origin 的前台 GET，排除认证控制路径。 |
| 存储 | 配对使用 Keystore 加密，网页数据位于沙箱；关闭云备份和设备迁移，签名／TLS 私钥不得进入仓库。 |

## 构建

使用 Android Studio 或 Android SDK 36 与 JDK 17；仓库包含 Gradle 9.8.2 Wrapper。

```powershell
Set-Location apps/mobile/android
./gradlew.bat :app:lintDebug :app:testDebugUnitTest :app:assembleDebug -x :app:lintAnalyzeDebugUnitTest -x :app:lintAnalyzeDebugAndroidTest
```

Debug APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。正式发布沿用只保存在仓库 Secrets 中的签名密钥，本地未签名 Release 构建或 Debug 安装不能替代正式签名核验。

每次构建默认自带实验性 iroh 传输。需要 Rust 1.99.1（含 `aarch64-linux-android` 与 `x86_64-linux-android` 目标）与明确指定的 NDK：

```powershell
Set-Location apps/mobile/android
./gradlew.bat :app:assembleDebug -PirohNdk=C:/Android/Sdk/ndk/25.2.9519653 -x :app:lintAnalyzeDebugUnitTest -x :app:lintAnalyzeDebugAndroidTest
```

传 `-PirohNative=false` 可走免工具链的快速通道，构建的是不包含 iroh 传输的原 HTTPS 外壳，`IrohNative` 会报告自身不可用。使用 iroh 需要完整版构建。传输库生成在 `app/build/generated/iroh/jniLibs/` 下，永不提交。启用原生库的构建不改变包名与既定正式签名；实验阶段的独立 alpha 签名在这里不使用。

原生构建还会从固定提交的官方 Maven 归档引入与 `native/Cargo.lock` 匹配的 JVM TLS 校验组件。必须保留其 JNI／Proguard 规则，仅打包 `.so` 不足以完成接入。APK 验证会检查 Debug 和压缩后的 Release 是否保留所需 JVM 类和原生入口名称。

当前源码的 Debug 构建使用包名 `io.github.sayach.dshmobile.debug` 与 `-debug` 版本后缀，可与正式 App 并存，存储和配对彼此独立。它不会升级或迁移旧版无后缀 Debug 应用；切换包名时应保留旧应用和数据，不要为此卸载或清除。Release 构建继续使用 `io.github.sayach.dshmobile` 与既定正式签名。

已核验的正式版本为 [Android 0.7.5](https://github.com/saya-ch/dsh-mobile/releases/tag/android-v0.7.5)，构建 90。兼容版与完整版分别附有对应的 `.sha256` 校验文件；两个公开下载均沿用正式发布签名及包名 `io.github.sayach.dshmobile`。旧版本历史集中在 [CHANGELOG](../../CHANGELOG.md)。
